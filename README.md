# مطابقة الجرد

تطبيق أندرويد أصلي يعمل بدون إنترنت لمطابقة جرد خزانات المحطة.

## الخزانات الافتراضية
1. ديزل رئيسي — طول 739 سم، قطر 276 سم
2. ديزل احتياط 1 — طول 676 سم، قطر 276 سم
3. ديزل احتياط 2 — طول 676 سم، قطر 310 سم
4. بترول — طول 739 سم، قطر 276 سم

يمكن تعديل الاسم والأبعاد من الإعدادات.

## الوظائف
- حساب حجم الخزان الأسطواني الأفقي من التمتير بالسنتيمتر.
- حفظ محلي في SQLite بدون إنترنت.
- لا يسمح بالحفظ إذا كان التمتير أو الرصيد ناقصًا.
- لا يسمح بتمتير أكبر من قطر الخزان.
- سجل جرد غير قابل للحذف من الواجهة.
- PDF لكل جرد.
- Excel XLSX لكل جرد دون مكتبات خارجية.
- تقرير فترة PDF.
- اسم المحطة والشعار من الإعدادات.
- واجهة عربية RTL.
